## 3. 鉴权

每个请求携带四个请求头：

```
X-Api-Key:    {api_key}
X-Timestamp:  {Unix 秒}
X-Nonce:      {随机串，每次不同}
X-Signature:  {HMAC-SHA256 十六进制}
```

签名规则：

```
待签串 = METHOD + "\n" + PATH + "\n" + TIMESTAMP + "\n" + NONCE + "\n" + SHA256(BODY)
签名   = HMAC-SHA256(api_secret, 待签串)
```

- `PATH` 不含域名与 query，例如 `/v1/jobs/abc123`
- GET 请求 BODY 为空，其 SHA256 为 `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`
- 上传图片时 BODY 为图片原始字节
- 时间戳与服务端偏差需在 5 分钟内

参考实现（Python）：

```python
import hashlib, hmac, time, uuid

def build_headers(api_key, api_secret, method, path, body=b""):
    ts, nonce = str(int(time.time())), uuid.uuid4().hex
    payload = "\n".join([method.upper(), path, ts, nonce,
                         hashlib.sha256(body).hexdigest()])
    return {
        "X-Api-Key": api_key,
        "X-Timestamp": ts,
        "X-Nonce": nonce,
        "X-Signature": hmac.new(api_secret.encode(), payload.encode(),
                                hashlib.sha256).hexdigest(),
    }
```

提供的 `videoapi.py` 已封装签名，可直接使用。

## 6. 完整流程（带参考图）

```
1. POST /v1/jobs                   提交需求
2. GET  /v1/jobs/{id}              轮询至 status = awaiting_assets
3. POST /v1/jobs/{id}/assets/{key} 按素材上传参考图（可跳过）
4. POST /v1/jobs/{id}/start        开始生成
5. GET  /v1/jobs/{id}              轮询至 status = done
6. 下载 video.url                  24 小时内有效
```

### 6.1 素材从哪来

当 `status` 变为 `awaiting_assets`，任务对象会返回需要保持一致的素材：

```json
{
  "status": "awaiting_assets",
  "needs_assets": true,
  "assets": [
    {
      "key": "char_woman",
      "type": "character",
      "name": "女孩",
      "description": "二十出头，低马尾，米色卫衣",
      "has_ref": false
    },
    {
      "key": "scene_store",
      "type": "scene",
      "name": "深夜便利店",
      "description": "冷白日光灯，玻璃窗外雨夜街道",
      "has_ref": false
    }
  ]
}
```

`type` 取值：`character`（人物）、`scene`（场景）、`prop`（道具）。

界面按该列表渲染上传位即可，**上传时使用 `key` 作为路径参数**。

### 6.2 上传参考图

```http
POST /v1/jobs/{job_id}/assets/char_woman
Content-Type: image/jpeg

<图片二进制>
```

- 单个素材重复上传会覆盖前一张
- 人物建议使用正脸、光线均匀的照片
- 不上传也能生成，直接进入下一步

### 6.3 开始生成

```http
POST /v1/jobs/{job_id}/start
```

## 7. 任务状态

| 状态 | 含义 | 建议动作 |
|---|---|---|
| `queued` | 排队中 | 继续轮询 |
| `analyzing` | 正在拆解分镜（约 20–30 秒） | 继续轮询 |
| `awaiting_assets` | 可上传参考图 | 展示素材清单，或直接调用 `start` |
| `generating` | 生成中 | 继续轮询，可用 `progress` 展示进度 |
| `assembling` | 合成中 | 继续轮询 |
| `done` | 完成 | 下载 `video.url` |
| `failed` | 失败 | 查看 `error.message` |
| `canceled` | 已取消 | 结束 |

轮询间隔建议 3–5 秒，进入 `done` / `failed` / `canceled` 后停止。

## 8. 幂等

提交时附带 `Idempotency-Key` 请求头（建议使用贵方业务单号）：

```http
POST /v1/jobs
Idempotency-Key: order-20241110-0001
```

相同 key 重复提交只会创建一条任务，适用于网络超时后的安全重试。

## 9. 错误响应

```json
{ "detail": { "code": "unauthorized", "message": "签名校验失败" } }
```

| HTTP | code | 说明 |
|---|---|---|
| 401 | `unauthorized` | 签名错误、时间戳超期或 nonce 重复 |
| 404 | `not_found` | 任务不存在 |
| 413 | `payload_too_large` | 图片超过 20MB |
| 422 | `validation_error` | 参数不合法 |
| 429 | `quota_exceeded` | 可用次数不足 |
| 429 | `key_disabled` | 密钥已停用 |

任务级的失败信息在任务对象中：`{"error": {"code": "video_failed", "message": "..."}}`。

## 11. Python SDK

`videoapi.py` 为单文件、零第三方依赖，放入项目即可使用（Python 3.9+）。

```python
from videoapi import VideoAPI

api = VideoAPI("https://video.awesomeimg.cn", "你的 api_key", "你的 api_secret")

job = api.run("雨夜天台上两个人对峙", duration_sec=8, save_to="./out.mp4")
print(job["video"]["url"])
```

需要用户参与选图时：

```python
job = api.create_job("雨夜天台上两个人对峙", duration_sec=8)
job = api.wait(job["job_id"], stop_at=("awaiting_assets", "done"))

if job["status"] == "awaiting_assets":
    for a in job["assets"]:
        print(a["type"], a["name"], a["key"])
    api.upload_image(job["job_id"], "char_man", "./hero.jpg")
    api.start(job["job_id"])

job = api.wait(job["job_id"])
api.download(job["job_id"], "./out.mp4")
```

接口方法：

| 方法 | 说明 |
|---|---|
| `create_job(brief, duration_sec, aspect_ratio, style, resolution, idempotency_key)` | 提交需求 |
| `get_job(id)` | 查询任务 |
| `get_storyboard(id)` | 获取分镜 |
| `list_assets(id)` | 获取素材 |
| `upload_image(id, asset_key, path_or_bytes)` | 上传参考图 |
| `start(id)` / `cancel(id)` | 开始 / 取消 |
| `wait(id, interval, timeout, stop_at, on_progress)` | 轮询至终态 |
| `download(id, out_path)` | 保存成片 |
| `run(...)` | 完整流程 |

## 12. 注意事项

1. **成片 24 小时有效**，过期后链接失效，请在收到 `done` 后及时转存到自有存储。
2. **`api_secret` 仅限服务端使用**，泄露后可能被他人消耗额度。
3. **提交任务即计一次用量**，参数请在上线前充分测试。
4. **网络超时重试请携带 `Idempotency-Key`**，避免重复创建任务。
5. 时长与参考图数量请按第 2 节的范围内传参，超出部分会被自动归整。

---

对接过程中如遇接口异常，请提供 `job_id`、请求时间与响应内容，便于定位。
